# 삭제 검토 후보 · 실제 변경 없음

2026-10-22. 후보만 기록한다. **원본을 삭제·이동하지 않았다.** references의 기존48개는 보존 대상이며 이 문서가 삭제 승인이 되지 않는다.

| 경로·종류 | 검토 이유 | 현재 처리 |
|---|---|---|
| `dist/` | 다시 만들 수 있는 빌드 | 보존. 납품 검증 뒤 재생성 가능 여부 확인 |
| `.cache/npm/` | 의존성 캐시 | 보존. 재설치·네트워크 조건 확인 후 별도 정리 |
| 임시 스크린샷·테스트 출력 | 반복 검증 중복 가능 | 보존. 최종 검증 근거와 구분 후 판단 |
| `public/assets` 교체 전 서비스 복사본 | 새 에셋 뒤 미참조 파일 가능 | 실제 소스/빌드 참조·출처·비교 용도 확인 전 확정하지 않음 |

다음은 삭제 후보에서 제외한다.

- `references/manifest.json` 기존48원본: 경로 존재·SHA256으로 보존 확인.
- `references/images`, `documents`, `archives`, `extracted`: 원본과 참고 이력.
- `references/generated`: 새 생성 원본·프롬프트·변환 이력.
- 출처/CREDITS·폰트 OFL·라이브러리 고지·과학 자료 출처.
- 관측 기록·기존 저장 복구본.

정리 시 절대 경로가 프로젝트 안인지 확인하고 참조·재생성·원본 보존을 확인한 후 별도 승인 범위에서 처리한다. 현재는 후보 문서 작성까지다.
