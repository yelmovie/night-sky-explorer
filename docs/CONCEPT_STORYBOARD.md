# 스테이지 개념영상

각 10초, 1280×720, 24fps. 관찰을 마친 완료 창에서 선택 재생하며 연구 노트와 설정에서 다시 볼 수 있다. 자막은 DOM으로 표시하고 영상에는 글자·음성을 넣지 않는다. 제작은 SVG + sharp + 로컬 FFmpeg이며 추가 유료 서비스는 사용하지 않는다.

각 컷은 고정 카메라 한 대다. 0~3.3초 관찰, 3.3~6.6초 변화와 비교, 6.6~10초 핵심 정리로 이어진다. 마지막 2초는 핵심 도형을 유지한다. 인물은 등장하지 않아 캐릭터 외형 변형이 없다.

| 장 | 프레임·시점 | CAMERA | SCENE / 종료 구도 |
|---|---|---|---|
| 1 달 표면 | 전체→표면 인서트, 정면 | 카메라 고정. 달 도형만 첫3초 천천히1.28배 확대 | 같은 달의 두 영역을 비교 원에 연결. 종료: 달과 밝고 어두운 표면 두 원을 유지 |
| 2 달 변화 | 전체 기록판, 정면 | 카메라 고정. 관측 시점만 왼쪽에서 오른쪽으로 이동 | 날짜 순서의 일곱 달 모형, 위에 변화하는 달. 종료: 마지막 달과 전체 기록 나란히 |
| 3 태양계 | 넓은 도형판, 평면 | 카메라 고정. 행성 도형이 순서대로 나타남 | 태양과 여덟 행성. 종료: 태양에서의 순서와 고리·표면 특징. 실제 크기·거리·공전 속도 모형이 아님을 자막 표시 |
| 4 빛의 근원 | 두 천체·빛 경로, 평면 | 카메라 고정. 광선만 순서대로 진행 | 태양 자체 발광→행성에 입사→관찰자 방향 반사. 종료: 두 색 광선과 눈 도형 |
| 5 별 배열 | 별 다섯 점, 정면 | 카메라 고정. 점 위치는 전체 영상에서 고정 | 청록 연결선→금빛 다른 연결선. 종료: 같은 별과 두 연결 패턴을 함께 유지 |

재생 실패 시 끝 장면과 모든 자막을 표시한다. 동작 줄이기에서는 재생 버튼으로 시작하고, 탭이 숨겨지면 영상을 멈춘다. 재생 창을 닫으면 디코더·다운로드를 해제하고, 완료 창 또는 목록으로 돌아온다. 영상 중 BGM·효과음은 쉰다.
