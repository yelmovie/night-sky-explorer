# 별빛 관측 연구소 · 디자인 기준 v2

2026-10-22. 교육용 관측 도구가 잘 읽히는 밤하늘 연구소다. 아기자기한 픽셀 지도와 제공 2D 일러스트를 연결하고 과학 자료·실제 조작 대상을 명확히 구분한다. 다음 값은 v2 목표이며 실제 적용·실측은 검증 문서에 남긴다.

기존 팔레트를 유지하고 토큰→공통 컴포넌트→개별 화면 순으로 적용한다. 배경을 가리는 큰 색 면 대신 그림·작은 가독성 받침·짧은 카드로 균형을 잡는다. 긴 영문 장식이 핵심 안내보다 커지지 않게 한다.

## 화면

- 좌상단 홈·이전, 우상단 소리·설정 네 아이콘만 그림 위에 띄운다. 상단바·하단띠·빈 장식 패널은 없다. 노트·도움말은 설정이나 맥락 안에서 연다.
- 위쪽 한 줄 질문, 중앙 큰 관찰 대상, 가까운 곳에 필요한 카드, 오른쪽 아래 현재 행동 하나. 완료 전 버튼은 이유와 함께 비활성화한다.
- 두 카드/사례는 현재 과제를 순서대로 안내하고 완료 결과만 작게 복기하게 한다. 안내 NPC를 누르면 말풍선이 열리며 입력 영역을 가리지 않는다.
- 설정은 제목·닫기·하단 초기화를 유지하고 본문만 스크롤한다. 학습·설정·결과의 버튼·글꼴 문법을 통일한다.

## 지도·보상·그림

지도만 사선2.5D다. 길과 문이 보이고 학생 연구원이 걸으며 달토끼가 따라온다. 건물·문 주변이 선택 대상이며 옆 목록이 있어야만 진행되는 구조를 피한다.

복구 전후는 시설 조명·문·연결 길로 표현한다. 탐구 표식은 건물 아래에 작게 두고 미션 기록·비교·도전에 연결한다. 코어는 실제 기록을 연결할 때 변화하고 복구돔 그림은 실제 복구 보상으로 쓴다.

필수13이미지와 기존 로고·배경·별여우를 활용한다. 행성8종은 기본 그림이며 실제3D를 연 경우에만 3D로 표시한다. 생성된 글자를 UI로 사용하지 않는다. 달 위상·날짜·좌표·표면 표시·선과 기준은 코드로 정확하게 겹친다. 프레임은 관찰 표적과 입력을 가리지 않는다.

## 반응형·접근성

1280×800·1024×600 가로는 질문·대상·주 행동이 화면 안에 보이게 한다. 375px 세로는 글자를 줄이기보다 순서를 보존해 스크롤한다. 한글은 어절 줄바꿈을 쓰고 라벨을 잘라 숨기지 않는다.

드래그 대체 버튼, 키보드 포커스, 모달 Esc/포커스 복원, 동작 줄이기를 제공한다. 실제 화면·터치 확인 전에는 대비·가독성·반응형을 통과로 기록하지 않는다.
