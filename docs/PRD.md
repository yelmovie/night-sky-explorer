# 별빛 관측 연구소 · PRD v2

설계 기준일: 2026-10-22. `UPGRADE_SPEC.md`를 제품 계약으로 삼는다. 이 문서는 구현·인수 기준이며, 통과 여부는 `VALIDATION.md`와 최종점검 보고서에 실제 실행 근거로 기록한다. 기존 원본 48개와 과거 관측 기록을 보존한다.

## 목적과 범위

학생이 관찰 도구를 조작하고 처음 생각과 자료를 비교·수정해 다섯 관측 결과를 만든다. 결과로 연구소 시설과 중앙 코어를 복구한다. 밤하늘이 고장 났다는 설정이나 속도·클릭량 보상은 사용하지 않는다.

흐름은 메인 → 선택 지도 → 5장×A/B → 중앙 코어 → 개인 결과다. 메인·시설 내부·보상은 2D, **선택 지도만 사선 시점 2.5D 픽셀 RPG**다. 학생 연구원이 길을 걸으며 달토끼가 실제 지나온 길을 따라온다. 별여우는 의뢰·근거 피드백 NPC다. 이동 캐릭터는 추후 교체할 수 있다.

3장 기본 조사 대상은 생성한 **8행성 그림**이다. 선택한 행성만 실제 Three.js 3D로 관찰하는 선택 도구를 둔다. 그림을 실제 3D로 표시하지 않는다. 다른 장의 활동에는 3D를 넣지 않는다.

### 분량과 단계 안내

v1 대비 필수 관찰·비교 단위를 2배로 늘린다. 단순 버튼 반복 대신 두 비교 카드·두 상황·두 하늘 영역을 사용하며 순서 카드로 한 번에 한 과제를 안내한다.

## 재미·보상

각 장은 사건 → 도구 조작 → 눈앞의 변화 → 내 기록 → 시설 복구로 이어진다. 렌즈·시간 기록소·행성 연구실/모형·판별 데크·북쪽 지도가 복구되며 다음 문과 길이 밝아진다. 지도에서 문에 도착하면 입장한다.

장마다 새 상황에 근거를 적용하는 선택 도전 하나를 둔다. 건물 아래 탐구 표식 3개는 미션 기록·두 비교 완성·선택 도전에서 계산한다. 선택 도전은 필수 학습 완료를 막지 않는다. 제한시간·목숨·속도·첫 시도 점수는 없고 오답은 구체적 단서와 함께 고친다.

이 표는 설계 인수 기준이다. 실제 재미·난이도·완주 시간은 학생 관찰 전 측정 완료로 표시하지 않는다. 각 시설의 첫 안내에는 이번에 할 일·완료 보상·다음 조작을 한 문장씩 제시하고, 이미 완료한 자료는 선택 상태·짧은 문구로 구분한다.

### 최종 보상과 생활 전이

다섯 실제 기록을 코어의 알맞은 자리에 연결하고 각도를 맞추면 복구된 돔 장면과 개인 기록을 보여 준다. 인증서에는 별명과 실제 관측 결과를 연결하며 관리자 예시에는 발급 버튼을 열지 않는다. 마지막 안내는 “나는 달의 표면을 비교할 수 있어요 / 자료를 보고 별과 행성을 구분할 수 있어요”처럼 수행 능력으로 마친다. 실제 관측은 보호자·교사의 안전 안내와 함께 여러 날 같은 방법으로 기록하도록 제안한다. 태양을 망원경이나 눈으로 직접 관측하도록 안내하지 않는다.

## 공통 화면·설정·저장

- 그림 위 좌상단 **홈·이전**, 우상단 **소리·설정** 네 아이콘만 띄운다. 상단바·하단띠·큰 불투명 패널을 없애고 한 줄 질문·큰 조작 대상·작은 카드·우하단 행동 하나로 구성한다. 안내원을 누르면 말풍선이 열린다.
- 설정 순서: BGM → 효과음 → BGM 음량 → 이야기 다시 보기 → 완료 후 엔딩·인증서 → 앱 정보/배움·보상 → 학생 가이드 → 교사 가이드 → 저작권/출처 → 확인 초기화·닫기. BGM·효과음은 별도 토글, 상단 소리는 함께 음소거한다.
- 교사 가이드의 **관리자 전체 해금 하나**로 모든 화면을 열고 다시 누르면 닫는다. 비밀번호·화면별 해금은 없다. 실제 증거·보상·인증서를 만들지 않는다. 예시 코어·결과는 메모리에만 두고 예시라고 표시한다.
- 별명만 받고 현재 브라우저에 초안·진행·증거를 자동 저장한다. 홈에서 이어한다. v1 기록을 보존해 이관하며 새 과제를 임의 완료시키지 않는다. 초기화는 별명·진행·보상·활동 삭제를 확인하고 소리 설정은 유지한다.
- 가로 태블릿 본문 18px 이상, 터치 목표 48px 이상, 키보드·버튼 대체 조작·포커스·동작 줄이기를 제공한다. 좁은 세로에서는 자연스럽게 스크롤한다.

로그인·서버·분석 전송·새 영상 제작·외부 공개 배포는 범위 밖이다. 납품 수준 목표와 실제 확인 결과를 구분하고 미검증 항목을 10점 충족으로 표시하지 않는다.

“10점 수준”은 목표다. 핵심 흐름·입력 차단·저장 복원·관리자 분리·화면 실측을 근거로 인수하며, 학생 학습효과·30명 교실망·상업 배포 권리처럼 이번 환경에서 확인하지 못한 항목은 별도 인수 조건으로 남긴다.
