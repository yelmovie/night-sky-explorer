# 별빛 관측 연구소 장별 시나리오 논의안

2026-10-14. 구현 전 대화용 정리야. 기존 심화 설계 v2의 이야기와 학습 활동을 유지하면서, 이번에 지정한 화면 표현과 공통 UI를 반영했어. 세부 수치·조작·MVP 범위는 아래 제안으로 구분해뒀어.

## 이번 대화에서 확인한 방향

- 메인 다음에 자연 속 스테이지 선택 맵을 둬.
- 선택 맵만 위에서 사선으로 내려다보는 2.5D 픽셀아트 RPG로 만들고, 캐릭터가 걸어가 장소에 들어가.
- 장소 내부는 기존 시안 계열의 2D 게임 화면이야.
- 사용자가 추가로 선택한 예외는 **2D 행성 조사 화면 안의 3D 행성**이야. 태양계 배치 화면·달·별자리·엔딩 전체를 3D로 만들지 않아.
- 모든 화면에 좌상단 홈·이전, 우상단 소리·설정을 둬.
- 설정에서 관리자 전체 해금을 한 번에 적용해. 장별로 나눈 해금 조작은 두지 않아.

## 내가 이해한 전체 이야기

학생은 신입 별빛 관측 연구원이야. 밤하늘은 정상인데 연구소의 관측·기록·분류 시스템이 서로 맞지 않는 자료를 보내고 있어. 별여우 연구관의 의뢰를 받아 다섯 관측 구역을 조사하고, 달토끼 기록원이 보관하는 연구노트에 결과를 모아. 마지막에는 그 다섯 기록으로 중앙 관측 코어를 복구해.

```text
2D 메인과 짧은 사건 소개
  → 2.5D 자연 속 선택 맵
  → 장소 진입 → 2D 학습 A → 2D 학습 B
  → 연구 기록 획득 → 선택 맵의 해당 시설 복구
  → 다음 장으로 이동
  → 다섯 기록 통합 → 2D 중앙 코어 복구 → 관측 기록·인증서
```

5장 × 학습 화면 2개 = 핵심 학습 화면 10개야. 메인·선택 맵·최종 복구·결과는 그 밖의 공통 화면으로 세어야 해.

## 장별 시나리오

| 장 | 사건과 장소 제안 | 첫 화면에서 할 일 | 다음 화면에서 할 일 | 기록과 복구 보상 |
|---|---|---|---|---|
| 1장 초점을 되찾아라 | 숲길 끝 달 관측대의 영상이 흐릿해 | 망원경 시야를 움직여 달을 잡고 배율·초점을 맞춰 촬영 | 달의 여러 지점을 확대하고 사진 두 장을 비교 | 달 표면 관측 기록. 망원경과 관측대 조명이 켜져 |
| 2장 끊긴 달빛 기록을 복원하라 | 호숫가 시간 기록소의 여러 날 기록이 끊겼어 | 시간 슬라이더를 움직여 서로 다른 시점의 달을 기록 | 빈 시점의 달 모습을 직접 예상하고, 시간을 진행해 겹쳐 비교·수정 | 달 변화 타임라인. 기록 장치와 달력 링이 작동해 |
| 3장 행성 자료를 정리하라 | 언덕 위 행성 연구실에서 행성의 이름표가 섞였어 | 2D 조사대 속 3D 행성을 돌리고 확대해 특징을 모은 뒤 후보 판단 | 조사 노트를 참고해 2D 태양계 모형에 태양과 8행성을 배치 | 태양계 연구 기록. 연구실 표시와 모형이 완성돼 |
| 4장 별빛 판별 회로를 검증하라 | 별빛 관측 데크의 분류기가 근거 없이 판단해 | 밤하늘의 별·행성을 관측하고 제공된 과학 자료와 비교 | 별 또는 행성이라는 주장에 적절한 증거를 연결 | 별·행성 판별 보고서. 분류 회로가 정상화돼 |
| 5장 북극성 주변 관측 지도를 복원하라 | 북쪽 전망대의 별자리 기준 레이어가 꺼졌어 | 북극성 주변으로 지정된 영역에서 선 없는 별 배열을 관찰 | 먼저 내 패턴을 기록한 뒤 기준 레이어를 켜서 비교·수정 | 별자리 관측 지도. 마지막 시설과 중앙 돔으로 향하는 불빛이 켜져 |

자연 속 장소 이름과 배치는 이번 제안이고, 기존 v2에서 확정된 지형은 아니야.

### 1장 달 표면 관측

달을 바로 누르는 활동보다 망원경의 시야·배율·초점이 실제로 바뀌는 경험이 중심이야. 촬영한 뒤에는 학생이 지점을 골라 밝고 어두운 부분, 움푹 팬 형태를 비교해. 자료에서 확인할 수 있는 특징만 기록하고, 정해진 숨은 정답 지점을 찾아야 하는 방식은 피하자.

### 2장 달의 변화

여러 날의 변화를 짧은 시간에 넘겨 보면서 스스로 기록을 만들어. 뒤 화면에서는 앞서 저장한 관측사진을 참고해 빈 시점의 밝은 영역을 조절하고, 예상과 관측 자료를 겹쳐 봐. 날짜 암기나 위상 변화의 원리 설명보다 관찰·예상·수정을 다뤄. 실제 오늘의 하늘이 아니라 학습용 시간 시퀀스라는 표시가 필요해.

### 3장 행성 조사와 태양계 구성

첫 화면에서 행성 한 개만 3D로 보여줘. UI·연구실·NPC는 2D로 유지해. 회전과 확대에 따라 줄무늬·고리·표면 무늬를 볼 수 있고, 기록한 특징이 후보를 고르는 근거가 돼. 모든 학생이 똑같은 위치를 반복 스캔해야 하는 과제는 줄이자.

다음 화면은 2D 태양계 배치판이야. 행성 외형만으로 태양에서의 순서를 추론하게 하지 않고, 조사 노트에 별도로 제공한 순서 자료를 참고할 수 있어야 해. 노트를 두 번 열었다는 클릭 횟수보다 기록을 배치 판단에 활용했는지가 중요해. 모형은 실제 크기·거리 비율과 다르다고 표시해.

### 4장 별과 행성의 근거 판별

밤하늘의 밝기·색·깜빡임만으로 정답을 정하지 않아. 관측 화면과 함께 제공된 과학 자료를 근거로, 별이 스스로 빛을 내는 천체라는 개념을 연결해. 분류만 맞고 이유가 맞지 않으면 어떤 자료를 다시 비교할지 알려줘. 사진만 보고 스스로 빛을 내는지 알아낼 수 있다고 표현하지 않아.

### 5장 별자리 패턴

북극성의 위치를 찾아내는 문제가 아니라, 지정된 북극성 주변의 별 배열을 관찰하는 활동이야. 처음에는 정답 연결선을 숨겨. 학생의 자유 패턴은 틀렸다고 평가하지 않고, 기준 별자리와의 비교를 수행한 뒤 자신의 기록을 수정하거나 설명하게 해. 별 위치와 기준 연결선은 생성 배경이 아니라 검수된 자료로 구현해야 해.

## 마지막 장면

달토끼가 모은 다섯 기록을 별여우와 함께 확인해. 학생이 연구 기록을 중앙 장치의 알맞은 입력부에 연결하고 마지막 보정 링을 돌리면 2D 연출로 돔이 열려. 결과 화면에는 실제로 만든 달 사진·예상·행성 증거·판별 근거·별자리 선이 남아야 해.

별이나 달 자체를 복구하는 이야기는 아니야. 학생이 복구하는 것은 연구소의 관측·기록 시스템이야.

## 재미와 몰입을 높이는 MVP 제안

1. **선택 맵의 변화:** 장 완료 후 해당 시설의 창과 길의 조명이 켜져. 진행률 숫자와 함께 눈에 보이는 결과를 줘.
2. **관측 행동의 반응:** 초점이 선명해지고, 시간에 따라 달이 달라지고, 행성을 돌리면 다른 무늬가 보여야 해. 누를 수 있는 버튼 수보다 조작 결과가 중요해.
3. **내 기록의 재사용:** 달 관측사진은 예측에, 행성 조사 노트는 태양계 배치에, 다섯 결과는 마지막 복구에 사용해.
4. **짧은 재도전:** 틀리면 처음부터 다시 시작하지 않고 현재 초점·예상·근거·연결선을 바로 고칠 수 있게 해.
5. **역할 있는 NPC:** 별여우는 의뢰와 힌트, 달토끼는 기록 보관과 비교를 담당해. 핵심 조작 대상을 가리지 않게 배치해.

맵 이동은 분위기를 만드는 짧은 구간으로 제안해. 이미 방문한 장소는 빠른 이동을 지원하고, 복잡한 길찾기·전투·반복 채집은 이번 MVP 범위에 넣지 않는 게 좋아.

## 공통 UI 동작 제안

- 홈: 현재 관측 상태를 저장한 뒤 2D 메인으로 이동. 메인에서도 아이콘 위치는 유지해.
- 이전: 앱 내부의 직전 화면으로 이동. 학습 A에서는 선택 맵, 학습 B에서는 A로 돌아가며 작성 내용은 유지. 외부 브라우저 기록을 그대로 뒤로 가지 않아.
- 소리: 음소거를 한 번에 전환하고 페이지가 바뀌어도 유지.
- 설정: 음향·동작 감소 등의 설정과 `관리자 전체 해금` 단일 선택을 제공.
- 전체 해금: 다섯 장·하위 화면·최종 장면을 한 번에 접근 가능하게 해. 해금과 학습 완료는 분리해 관측 기록을 자동으로 채우지 않아. 기록 없이 최종 장면을 확인할 때는 별도 미리보기 데이터임을 표시하고 실제 결과에 저장하지 않는 방안을 제안해.
- 관리자 선택을 해제하면 실제 완료 기록에 따른 잠금으로 돌아가. 완료 기록은 지우지 않아.
- 아이콘의 터치 영역은 48×48px 이상으로 제안해.

## 3D를 넣는 범위

| 화면 | 방향 |
|---|---|
| 자연 속 선택 맵 | 2D 타일과 스프라이트로 깊이를 표현하는 2.5D. 실시간 3D 맵 불필요 |
| 3장 첫 화면 | 2D 패널 안의 행성만 3D 회전·확대. 이번 대화에서 선택됨 |
| 3장 두 번째 화면 | 2D 태양계 배치와 기록 확인 |
| 달·별자리·엔딩 | 2D 유지 |

## 다음 설계에서 확정할 것

- 선택 맵에서 움직일 캐릭터: 학생 연구원 아바타 또는 제공된 달토끼를 플레이어로 활용.
- 처음부터 행성 8개를 모두 상세 조사하게 할지, 대표 3개를 필수 조사하고 나머지는 자유 열람하게 할지. 수업 길이를 고려해 후자를 제안해.
- 기존 Science World의 실제 공통 코드가 있는지. 현재 폴더에서는 실행 코드와 공통 UI 소스를 찾지 못했어.

이 논의를 맞춘 뒤 새 PRD에서 화면별 목표·완료 조건을, 새 TRD에서 맵 이동·학습 상태·저장·3D 뷰어·공통 UI를 구체화하면 돼. 이번에는 시나리오 확인과 자료 정리까지만 진행했어.
