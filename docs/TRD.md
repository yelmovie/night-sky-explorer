# 별빛 관측 연구소 · TRD v2

설계 기준일: 2026-10-22. Vite + JavaScript ES modules + CSS + Canvas 2D + Three.js를 유지하는 로컬 우선 정적 앱이다. 완료 조건은 `PRD.md`·`UPGRADE_SPEC.md`, 실제 통과 근거는 `VALIDATION.md`를 따른다.

## 책임과 렌더링

| 영역 | 책임 |
|---|---|
| `src/main.js` | 화면 전환, 한 과제씩 안내, 입력·피드백, 공통 아이콘, 기록·보상·설정 대화상자 |
| `src/state.js` | 버전 검증·이관, 초안/실제 증거 분리, 입력별 완료·접근 판정, 저장 실패 복구 |
| `src/data.js`, `src/stars.json` | 장·천체·근거·별 좌표 데이터. UI 글자를 그림에 굽지 않음 |
| `src/drawing.js` | 정확한 달 위상·표면·위치 표시, 별 좌표 투영, 기존 공통 SVG 아이콘 |
| `src/map.js` | 사선 2.5D 지도, 길 그래프·도착·충돌, 학생 이동·이력 따라가는 달토끼, 시설 상태 |
| `src/planet.js` | 선택 대상 하나만 실제 3D 렌더. 회전·확대·실패 안내·화면 이탈 자원 정리 |
| `src/styles.css` | 토큰, 그림 위 UI, 입력 상태·반응형·인쇄·동작 감소 |
| `public/assets` | 제공 4이미지·서비스용 생성물·폰트·출처 고지. 실행 CDN 의존성 없음 |

새 모듈을 나누면 위 책임을 유지하고 실제 파일·호출 경계를 검증 기록에 반영한다. Remotion과 새 게임 프레임워크는 도입하지 않는다.

## 상태와 v1 이관

기존 저장 키는 `starlight-lab:v1`, 상태 버전은 1이다. v2는 확장 활동·증거·선택 도전·소리 설정을 포함한다. **이관 구현·테스트 전에는 이미 이관된다고 주장하지 않는다.**

1. 기존 JSON을 검증하고 원본을 보존한 뒤 v2 구조로 변환한다. 저장 키 변경 시 v1 읽기·복구본 경로를 명시한다.
2. 별명·소리·위치·사진·처음/수정 생각·근거·완료 증거를 보존한다. 단일 사진/패턴/예상은 첫 활동으로 옮긴다.
3. 새 2회 과제의 빈칸은 빈칸으로 둔다. v1 완료를 2회 완료로 복제하지 않고 과거 증거와 v2 새 기준 충족을 구분한다.
4. 손상된 JSON은 복구용 원본을 남기고 안전한 초기 상태를 제공한다. 객체·배열 길이·천체/필드 허용값·수치 범위를 제한한다.
5. 이관→저장→로드→재저장을 검증한다. 저장 거부·용량 오류는 알리고 메모리 세션을 계속한다.

지속 상태는 별명, 장면/이어하기, 소리·동작 설정, 방문, 초안, 실제 증거, 선택 도전, 실제 코어 복구, 갱신 시각이다. 초안 수정 중 기존 완료 증거를 보존하고 새 완료 때 스냅샷을 갱신한다. 최초 예상·자유 패턴은 자료 공개 전에 고정한다. 결과·인증서는 실제 증거만 읽는다.

## 입력별 판정

| 장 | A | B |
|---|---|---|
| 달 | 중심·초점 유효 사진2, 서로 다른 배율 | 카드2 각각 표면2곳+관찰 문장 |
| 달 변화 | 전반·후반 포함 서로 다른 6시점 | 14/24일 각각 최초 예상·공개·겹침·수정·설명 |
| 행성 | 지정6행성 특징·천체 근거 | 태양+8행성 순서 및 8행성 암석/가스/얼음 묶기 |
| 별·행성 | 서로 다른 8자료 비교 | 8천체 주장·빛의 근원 근거 일치 |
| 별 배열 | 관찰6별, 영역별2개 이상 | 영역별2선 이상 선공개 저장·기준 비교·설명 |

중복 선택으로 개수를 늘리지 않는다. 같은 검증 함수를 버튼 활성화·최종 저장에 사용한다. 드래그·선 연결·시야 조절은 Pointer Events/터치 캡처와 선택→버튼 배치 같은 대체 조작을 제공한다. 완료·전환의 중복 실행을 막고 오답 때 초안을 유지한다.

관리자 해금은 접근 함수에만 영향을 준다. 실제 완료·표식·코어·인증서 판정에 넣지 않는다. 예시 데이터·코어 연결/각도는 메모리에만 두고 저장·내보내기·인증서에 섞지 않는다. 해제 뒤 실제 진행 접근으로 돌아간다.

## 지도·에셋·3D

지도 그림은 장식, 길·문·잠금은 데이터 레이어다. 목적지 선택 시 길 그래프로 이동하고 문 범위 도착 뒤 입장한다. 키보드도 같은 충돌·도착 규칙을 쓴다. 달토끼는 주인공의 이전 위치 이력을 따라온다. 동작 줄이기에서는 이동을 즉시 마치되 도착·입장 조건을 유지한다.

필수 이미지13종: 지도1·학생보행1·달토끼보행1·행성8·망원경프레임1·복구돔1. 생성 원본은 `references/generated`, 서비스 파일은 `public/assets/generated`에 둔다. 과학 좌표·위상·연결선·숫자·UI는 코드로 표시하고 원본을 덮어쓰지 않는다.

3장 기본은 행성 그림이다. 선택한 대상만 Three.js 구체+필요한 고리로 렌더하며 CSS 회전을 실제3D라고 부르지 않는다. 모형의 크기·거리·표면 한계를 알린다. WebGL 실패 시 미지원 안내와 그림·자료로 계속한다. 화면 이탈 시 RAF·이벤트·geometry/material/texture·renderer/context를 정리한다.

## 공통 화면·소리·설정

좌상단 홈·이전, 우상단 소리·설정 네 SVG만 그림 위에 띄운다. 상·하단 띠를 두지 않는다. `<dialog>`·Esc·포커스 복원·접근성 이름·48px 터치를 제공하고 설정 제목/닫기·하단 초기화를 화면 밖으로 밀지 않는다.

설정 순서는 BGM/효과음/BGM음량 → 이야기 → 완료 후 엔딩·인증서 → 앱정보 → 학생 → 교사(성취기준·단일 전체해금) → 저작권/출처 → 확인초기화/닫기다. BGM 꺼짐이면 음량도 비활성화한다. 초기화 후 소리 설정은 유지한다. 오디오는 첫 사용자 조작 후 시작하고 이야기·엔딩·화면 전환 때 중첩을 막는다. 음량은 BGM에만 적용한다.

## 실행·보존·검증

`start.cmd`는 프로젝트에서 Vite 5183포트를 사용하며 TEMP/TMP는 `D:\DevTemp`, npm 캐시는 프로젝트 `.cache/npm`이다. `npm test`, `npm run build`, `npm run preview`로 확인한다. 결과·다운로드·캐시·임시·생성물은 D:에 둔다. 최초 오프라인 실행을 보장하는 서비스워커는 범위 밖이다.

- 단위 검증: v1 이관 왕복·손상/금지 저장, 각 입력·중복·오답 판정, 관리자와 실제 증거 분리, 선택 도전/표식, 실제 코어 조건.
- 브라우저: 일반 10활동→코어→결과, 미완료 차단·수정, 길·문·동행, 홈/이전/재개/새로고침, 소리·설정·초기화, 그림/실제3D·실패 대체.
- 시각: 1280×800·1024×600·375px에서 글자·잘림·겹침·터치·대화상자와 콘솔/네트워크 확인.
- 원본: `references/manifest.json` 기존48항목의 `CurrentPath` 존재와 SHA256 일치. 새 생성물 때문에 기존 manifest 항목을 바꾸지 않는다.
- 권리: `public/assets/CREDITS.md`의 확인/미확인, 폰트·라이브러리 원문 고지 동봉 확인. 외부 공개 배포는 하지 않는다.

실행 결과·점수·미측정·권리 미확인은 `VALIDATION.md`·최종점검 보고서를 기준으로 한다.
