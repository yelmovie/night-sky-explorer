# 고도화 구현 계약 · 2026-10-22

사용자의 이번 요청은 아래 고도화와 수정에 대한 실행 승인이다. 기존 원본과 관측 기록을 보존한다. 런타임은 Vite/JS/Canvas/Three.js 유지. 메인·실내·보상은 2D, 선택 지도만 사선 2.5D 픽셀 RPG. 3장 행성 대상만 선택적으로 실제 3D 관찰 가능하다. 생성 행성 이미지는 회전 가능한 3D 에셋으로 가장하지 않는다.

## 교육 활동: 기존 대비 2배

| 장 | A | B | 보상과 다음 연결 |

두 차례 활동은 순서 카드로 나눠 한 번에 한 과제만 제시한다. 날짜 숫자는 음력이 아닌 학습 시퀀스다. 달 변화 원인을 평가하지 않는다. 행성 색만으로 판별하지 않는다. 별자리 탐색은 북극성을 찾는 상위 추론 대신 주어진 기준 주변 배열 관찰이다.

## 재미와 보상

각 장: 사건→관찰 도구 조작→결과가 눈앞에서 달라짐→내 기록→시설 복구. 제한시간/목숨/속도 점수 없음. 실패하면 현재 상태에서 단서와 함께 수정. 학생은 지도에서 학생 연구원을 조종하며 달토끼가 실제 지나온 길을 따라온다. 다음 시설의 문과 길이 밝아지며 문에 도착하면 입장한다. 중앙 코어는 실제 다섯 증거만 연결한다. 관리자 예시는 메모리에만 두고 인증서를 발급하지 않는다.

선택 도전 한 개씩: 새 관측 상황에 근거 적용. 미션 기록·두 비교 완성·선택 도전으로 건물 아래 탐구 표식 3개를 계산한다. 클릭량·속도·첫 시도는 보상 조건이 아니다. 개인 결과는 내가 할 수 있게 된 관찰·예상수정·근거판단을 진술하고 실제 증거를 함께 보여 준다.

## 화면·설정

그림 위 좌상단 홈·이전, 우상단 소리·설정만. 상단바·하단띠·큰 불투명 패널 제거. 활동 한 줄 질문·큰 조작 대상·필요한 크기의 카드·우하단 현재 행동 하나. 안내원은 눌러서 말풍선을 연다. 데스크톱/태블릿 가로에서 화면 내 배치, 좁은 세로는 읽을 수 있게 자연스럽게 스크롤.

설정 순서: BGM, 효과음, BGM음량, 이야기 다시보기, 완료 후 엔딩·인증서, 앱정보/배움·보상, 학생가이드, 교사가이드(성취기준·관리자 단일전체해금), 저작권/자료출처, 확인 초기화·닫기. 별명만 받고 로컬 저장. 별도 페이지별 관리자 해금 버튼 없음.
