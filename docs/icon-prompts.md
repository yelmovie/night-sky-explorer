# 공통 아이콘 사양

2026-10-22. 단순 UI 아이콘은 기존 `src/drawing.js`의 직접 작성 SVG를 유지한다. 이 목록을 위한 래스터 생성은 하지 않는다. 장식 그림은 별도 이미지 프롬프트 목록을 따른다.

| 위치 | SVG | 접근성 이름·동작 |
|---|---|---|
| 왼쪽 위 | `home` 집 | 홈. 시작 화면으로 가며 이어하기 위치 보존 |
| 왼쪽 위 | `back` 화살표 | 이전. 현재 화면 상위 단계로 이동 |
| 오른쪽 위 | `sound`/`mute` | 소리 끄기/켜기. BGM·효과음 함께 빠른 음소거, 상태 이름 갱신 |
| 오른쪽 위 | `settings` 톱니 | 설정. 소리·이야기·가이드·단일 전체해금·출처·초기화 |

SVG는 약22~26px, 실제 버튼 최소48px다. 같은 선 굵기·둥근 끝·현재색을 쓰며 이모지·여러 아이콘 세트를 섞지 않는다. 장식 SVG는 접근성 트리에서 숨기고 버튼에 한국어 이름을 준다. 버튼 상태는 디자인 기준을 따른다.

노트·잠금·복구·확인·확대 같은 활동 아이콘도 기존 SVG를 재사용한다. 전역 모서리에 추가하지 않는다. 잠금·완료에는 짧은 문구도 붙인다.

향후 장식용 이미지가 별도로 필요한 경우에만 쓸 보조 프롬프트:

> 밤하늘 관측 연구소의 작은 장식용 [대상] 아이콘. 기존 남색·별빛 금색·청록 팔레트, 둥글고 단순한 외형, 작은 크기에서 분명한 실루엣, 투명 배경, 글자·숫자·로고·워터마크 없음. 학습 정오답이나 정확한 과학 도형은 넣지 않음.

이 보조 프롬프트는 현재 생성이나 공통 SVG 교체를 뜻하지 않는다.
