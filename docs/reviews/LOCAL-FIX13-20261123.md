## 명령·권한 경고와 한계

- 복제 때 두 한글 문서 경로의 Unicode 정규화 충돌 경고가 있었다. Git 인덱스와 해당 문서는 손대지 않았다. 게임 에셋 요청 실패는 검증에서 없었다.
- 읽기 전용 샌드박스의 Git 조회는 macOS `/tmp/xcrun_db-*` 캐시 생성 거부를 출력했으나 종료 코드 0으로 상태·원격 정보를 반환했다. 이후 필요한 로컬 쓰기는 도구의 정상 권한 검토를 거쳐 실행했으며 시스템 임시 폴더·Git 전역 설정을 바꾸지 않았다.
- Playwright 설치 위치 탐색 중 `/Users/yel/Library/Caches/com.apple.*`, `CloudKit`, `familycircled` 보호 폴더에서 OS 읽기 거부가 났다. 그 탐색은 중단했고 보호 폴더 읽기 재시도·권한 변경을 하지 않았다. 이미 찾은 `/Users/yel/.local/node/lib/node_modules/playwright`를 사용했다.
- 의존성 위치 제공 도구는 “local threads only”로 지원되지 않았다. 한 탐색 셸에서 zsh의 특수 `path` 변수 사용으로 `rg`를 못 찾는 오류가 있었고, 그 자식 셸 안의 변수 이름을 바로잡았다. 호스트 PATH·앱 설정은 변경하지 않았다.
