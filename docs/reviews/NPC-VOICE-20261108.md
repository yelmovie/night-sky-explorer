# NPC 환영 음성 연결 검증

- 첫 화면에 수동 듣기/멈추기(최소 48px), 정확한 전체 자막, AI 생성 음성 표시를 추가했다. 자동재생하지 않는다.
- 기존 전체 소리 및 효과음 설정을 존중한다. 다른 UI 클릭, 화면 전환, 탭 숨김, 다른 미디어 시작 시 즉시 정지한다. 화면 교체 시 AbortController로 리스너를 해제하고 Audio 소스를 비운다.
- 재생 중 기존 배경음/효과음 우선순위를 낮추며 종료 시 복구한다. 빠른 재생/정지 반복의 비동기 응답 경합을 방지했다.
- 음원 누락/오프라인 실패 시 자막을 유지하고 학습 계속 가능 안내를 표시한다.

## 검증

- npm test: 75/75 통과. npm run build 통과.
- 격리된 실제 Chrome에서 AAC 재생시간 증가, 자동재생 없음, 수동 정지, 음소거, 숨김 이벤트, 화면이탈, 다른 미디어 이벤트, 빠른 재생/정지/재생, 음원 요청 실패 fallback 확인. 콘솔 pageerror 없음.
- 1024×768, 873×580, 390×844에서 버튼 크기/자막 경계 검사와 스크린샷 점검.
- 재현 스크립트: ../13 nightsky/scripts/qa-welcome-voice.mjs (13번 폴더 자체에서는 scripts/qa-welcome-voice.mjs). 스크린샷은 13번 .tmp/npc-qa/에 있다.
- 브라우저 디코딩 및 재생 진행을 검증했지만 스피커를 통한 주관적 발음·음질 청취는 하지 않았다. 탭 숨김은 visibilitychange 이벤트 경로를 검증했다.
- 기존 변경을 유지했으며 커밋·푸시·배포하지 않았다.
