## 적용한 변경

1. 단일 curriculum.js에서 정확한 기준 코드와 각 장의 목표·증거·오개념·평가 경계를 제공. 설정의 교사용 가이드와 테스트가 같은 데이터를 사용한다.
2. 지도 viewport 치수를 ResizeObserver로 캐시하고, 바뀌지 않은 transform/캔버스 상태는 다시 그리지 않는다. 이미지가 늦게 로드되어도 revision으로 다시 그린다.
