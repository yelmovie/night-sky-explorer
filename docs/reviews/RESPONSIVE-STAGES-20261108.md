# 스테이지 반응형·학습 시각화 개선

2026-11-08. 기존 사용자 변경을 보존하며 미션 1~5의 A/B 화면과 중앙 코어를 수정했다. 외장 USB 볼륨 T7 Shield의 연결·쓰기 가능 상태를 확인하고 소스, 브라우저 프로필, 임시파일, 캡처, 빌드와 로그를 모두 이 프로젝트 또는 외장 캐시에 저장했다.

## 수정 내용

| 영역 | 개선 |
| --- | --- |
| 공통 화면 | 제목·본문·하단 행동을 독립 grid 행으로 배치. 제목 줄 수가 늘어도 관찰 영역과 겹치지 않는다. 루미 안내·연구 키트·다음 버튼의 공간을 분리했다. |
| 좁거나 낮은 화면 | 세로는 관찰→조작→힌트→다음 행동으로 문서 스크롤. 높이 520px 이하는 문서 스크롤을 허용한다. 태블릿에서는 긴 패널을 스크롤한다. |
| 달 관측 | 방향 아이콘, 관측 순서, 촬영 대기·저장 표시를 보강했다. 표면 선택 번호·확대 카드 색을 연결하고 선택 지점 중심으로 확대한다. |
| 달 변화·예상 | 날짜순 관측 기록과 날짜별 달 그림을 표시한다. 내 예상/관측 제목은 분리하고 달 그림만 겹친다. 날짜·달·관찰 설명의 행을 분리했다. |
| 행성 | 선택 행성·확대·입체 조작을 묶었다. 확대는 그림 영역 안에서만 일어나며 라벨을 덮지 않는다. 순서 번호와 방향, 분류 근거·놓인 행성 이름을 표시한다. |
| 별·행성 | 태양빛→행성→관찰자의 빛 경로와 반사광, 가림판을 구분한다. 이름표 선택→판단 근거 순서를 표시한다. |
| 별자리 | 관찰 상태와 내 선/기준선 범례, 되돌리기·연결 조작을 구분했다. 기존 별 좌표·터치 반경·정답과 기록 규칙을 보존했다. |
| 중앙 코어 | 긴 기록과 보정 조작을 패널 스크롤로 접근할 수 있게 했다. 세로 태블릿은 세 패널을 문서 흐름에 배치했다. |

화면 렌더링을 `src/moon-stages.js`와 `src/space-stages.js`로 나누어 병렬로 작업했다. 공통 레이아웃은 `src/responsive.css`에서 관리하고, 기존 `mountLearning`의 입력·정답·저장·진행 규칙은 유지했다. 연구 키트 버튼에는 명시적으로 pointer events를 허용했다.

## 검증

- `npm test`: 75개 통과.
- `npm run build`: 통과. 의존성·잠금 파일 변경 없음.
- JS 문법 검사, `git diff --check`: 통과.
- `scripts/verify-playthrough.mjs`: 정상 학생 모드에서 미션 1~5 완료→최종 보고서→기록 연결→보정 링 드래그→코어 복구→인증서→새로고침 기록 복원까지 통과. 키보드·마우스·터치 드래그, 오답 수정과 중간 저장도 확인했다. 페이지 오류 없음. 원본 결과는 `.cache/classroom-qa/playthrough.json`에 있다.
- 브라우저: Chrome/Chromium, 터치 및 동작 줄이기 설정.
- 화면 크기: 1920×1080, 1366×768, 1280×800, 1024×600, 873×412, 740×360, 360×740, 768×1024, 800×270.
- 405개 고유 화면/상태 조합: 가로 넘침·글자 잘림·도달 불가/가려진 조작·아이콘/글자 충돌·페이지 오류 0건.
- 상태: 빈 입력/완성된 입력, 각 활동 탭, 예상 겹치기, 행성 2배 확대·3D·참고 자료 열기, 홈·지도·코어 연결 전후.
- 직접 확인: 달 선택점·확대 사진, 예상 겹치기, 행성 확대/라벨, 순서/묶음, 빛 경로, 별 연결선, 태블릿·세로·작은 가로 대표 캡처.

재현 스크립트는 `scripts/verify-responsive.mjs`다. 기존 로컬 Playwright 모듈과 브라우저 경로를 `PLAYWRIGHT_MODULE`, `BROWSER_EXECUTABLE`로 지정하고 `RESPONSIVE_QA_DIR`를 외장 경로로 지정한다. `QA_EXTENDED=1`은 3D를 포함한다. 기본 9종 검사를 재현하려면 `TEST_SIZES=1920x1080,1366x768,1280x800,1024x600,873x412,740x360,360x740,768x1024,800x270`을 사용한다.

최종 집계는 `.tmp/responsive-qa/verified-report.json`, 캡처와 원본 검사 결과는 `.tmp/responsive-qa/{final,additional,recheck}/`에 있다. 첫 검사에서 접힌 `<details>` 안의 참고 문장을 보이는 문장으로 판단한 오탐은 가시성 판정을 수정한 뒤 관련 화면을 재검사했다. 고유 화면/해상도가 중복될 때 최신 재검사 결과를 최종 집계에 사용하고 원본 보고서는 보존했다.

물리 태블릿·iPad/Safari와 교실 전자칠판은 미실측이다. 브라우저 내부 스크롤로 도달 가능한 내용과 행성 확대의 의도된 그림 크롭은 오류로 집계하지 않는다. 외부 배포는 수행하지 않았다.
