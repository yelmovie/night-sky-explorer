1. 작업 기록과 실제 파일을 대조하고 공개 영상 장면 이동, 복구 제목, 달 자동 관찰 동기화 문제를 재현했다.
2. 세로 태블릿의 축소 배치를 바로잡고 날짜 버튼·지도 이동·모바일 조작 공간을 정리했다.
3. 공식 성취기준과 10개 활동을 연결했다. 행성 성분 분류를 선택 탐구로 바꾸고 필수 기록·저장 검증을 추가했다.
4. 각 페이지에 핵심 과학 개념을 굵게 표시하고 현재 할 행동과 금색 조작 테두리를 같은 상태 판단으로 연결했다.
5. 달 표면 그림을 새로 생성해 적용하고, 현재 기능과 다른 힌트 글·음성을 교체했다.
6. 단위 검사, 직접 완주, 반응형, 기록 보호, 공개 파일 해시와 실제 공개 주소 기능을 재검증했다.
