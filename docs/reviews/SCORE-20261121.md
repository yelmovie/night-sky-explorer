## 이번에 본 것 가운데 감점 밖

- 개념영상 창은 지금 영상이 화면 전체를 덮는 디자인이라, 장면 버튼 줄(「4번째 장면」 등)은 영상 뒤에 깔려 눌리지 않는다(`elementFromPoint`가 영상). 다른 세션의 디자인 변경이라 고치지 않았고, 검사는 버튼에 클릭 이벤트를 직접 보내게 바꿨다.
- 세로 폰 375×812에서 결과 화면이 가로로 넘친다. 납품 기준(태블릿·전자칠판 가로) 밖이라 `verify-classroom` 기본 크기에서 뺐다.
