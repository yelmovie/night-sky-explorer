# 13 별빛 관측 연구소 개선 · 2026-11-07

## 범위와 판정
기존 미커밋 작업을 보존한 추가 개선이다. 1~5 참조 프로젝트 및 다른 단원은 수정하지 않았다. 커밋·배포·영구삭제·외부 전송 없음. **기록 안전/학습 흐름/반응형 범위 검증 완료, 전체 납품 판정은 보류**: 실제 학교 태블릿 성능·전체 라이선스 재검증·배포 서버는 미검증이다.

## 실제 적용
- 교사 시연을 학생 스냅샷과 분리. 시연 중 자동저장 금지, 종료 시 원래 상태 복원, 새로고침 시 학생 기록 복귀. 시연 중 초기화 금지. 파일 내보내기도 원래 학생 기록을 사용한다.
- 두 창의 저장 원본이 달라지면 덮어쓰기 중단. 읽기 실패·손상 JSON·저장 공간 오류에도 원본 보존. 화면에 지속 경고와 파일 내보내기를 제공한다.
- 초기화 전에 별도의 날짜별 원본 백업 보관. 백업 실패하면 초기화 금지. 복구는 해당 로컬 백업의 기술 지원 절차가 필요하며 앱 내 가져오기 UI는 아직 없다.
- 재완료로 최초 제출 근거를 덮어쓰지 않는다. 학습 초안은 계속 수정 가능하다.
- 선택 행성 3D DPR 상한 2→1.5. 기존 요청 시 렌더/해제 구조 유지. 실제 기기 FPS 개선 수치는 측정하지 않았다.
- 작은 화면/높이 600px 이하에서 루미 힌트와 연구 키트를 문서 흐름으로 이동. 별 연결 버튼을 가리던 고정 UI를 해소했다.

## 학습·단계 중복 점검
성취기준 근거: 기존 PRD/설정 및 docs/SOURCES.md의 [4과13-01~03]. 이번에 고시 원문을 다시 내려받아 확인한 것은 아니다.
1. 달: 조준·초점·서로 다른 배율 촬영 → 표면 두 지점 비교 기록.
2. 달 변화: 여섯 시점 관측 → 두 시점 예상·겹쳐 비교·생각 수정. 실제 날짜 예보가 아닌 북반구 모형임을 명시.
3. 행성: 외형 근거 조사 → 9개 천체 순서 및 8개 행성 분류·드래그. 크기·간격 실제 비율 아님.
4. 별/행성: 8개 자료 조사 → 빛의 근원으로 판별. 밝기·색만으로 정답 처리하지 않음.
5. 별 배열: 두 영역의 별 관측 → 자유 연결·기준선 비교·설명. 북두칠성은 큰곰자리 일부.
마지막 코어는 근거를 채널에 연결하는 요약·전이. 구조적 중복 없음. 행성 8개 분류 등 같은 조작의 반복은 있으나 서로 다른 근거를 확인하는 목적이 있다. 학생 실제 흥미·수업시간 효과는 미측정.

## 실제 개선 프롬프트
“13 nightsky의 기존 작업과 자산을 유지하라. 학생 최초 관측·예상·완료 증거는 시연과 재학습으로 덮어쓰지 말 것. 교사 시연은 임시 복제 상태에서만 작동하고 종료/새로고침 후 학생 상태로 복귀시켜라. 저장 원본 비교로 다른 탭 충돌/손상/읽기 실패를 보호하고 지속 경고·내보내기를 제공하라. 초기화 백업 실패 시 중지하라. 3D의 태블릿 DPR을 제한하고 작은 화면에서 NPC 안내가 학습 컨트롤을 덮지 않게 하라. 단위 회귀와 실제 5단계 플레이스루, 다양한 뷰포트를 검증하고 한계를 명시하라.”

## 자산 및 후속
기존 고품질 배경·달/행성 그림·NPC·개념영상과 Kenney 효과음/Web Audio BGM을 재사용. 불필요한 새 이미지/모모 호출 및 임시 생성물 없음. 신규 음성 품질 개선으로 주장하지 않는다. 교실 실기기 체험·백업 복원 UI·실배포 전수 검증이 다음 우선순위. 공유 graphify 갱신은 시리즈 전체 작업 종료 후 상위 작업에서 한 번 수행한다.
