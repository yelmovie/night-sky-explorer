# 한 화면 실험·중복 안내 정리·자동 관찰

2026-11-08 후속 요청. 대상은 미션 1~5의 A/B 학습 화면 10개다. 앞선 반응형 개선에서 사용하던 패널/문서 스크롤을 없애고, 실험과 현재 조작 및 다음 버튼이 한 화면에 들어오도록 바꿨다.

## 화면과 안내

- 제목 한 번, 실험, 필요한 조작, 하단 행동으로 정리했다. 반복되는 도구 제목·루미 말풍선·과정 설명·완료 문구를 제거했다.
- 힌트와 연구 기록은 하단 버튼으로, 긴 참고 자료와 앞선 관측 기록은 자료 버튼으로 연다. 실험과 조작을 가리는 별도의 상시 안내는 없다.
- 현재 필요한 조작에 금빛 테두리를 표시한다. 정답 선택 활동에서는 특정 정답을 강조하지 않고 선택지 묶음이나 필요한 입력을 안내한다.
- 망원경과 달 그림, 행성, 별 지도는 남은 영역을 채운다. 행성 배치와 별 관찰은 전체 폭을 사용한다.
- 태블릿 세로에서도 달의 원형 비율과 관찰 좌표가 일치하도록 가로·세로 중 작은 크기로 그림을 맞춘다.
- 작은 가로 화면은 최소 960×480, 작은 세로 화면은 최소 360×740의 논리 화면 전체를 뷰포트에 맞춘다. 작은 화면에서는 화면 전체와 터치 영역이 같은 비율로 축소된다.

## 자동 관찰

자동 관찰/일시정지/다시 보기와 0.5×·1×·2× 속도를 제공한다. 직접 조작하면 재생을 멈춘다. 탭 변경과 화면 이탈은 재생을 초기화하고, 숨겨진 문서와 열린 모달에서는 단계가 진행되지 않는다. 재렌더링에도 중복 타이머가 생기지 않는다.

| 활동 | 자동으로 보여주는 과정 | 학습자가 직접 하는 일 |
| --- | --- | --- |
| 망원경 | 시야·초점·배율 조절과 서로 다른 배율 사진 두 장 | 다음 활동 진행 |
| 표면 비교 | 두 위치 관찰과 확대 비교 | 발견한 차이 작성 |
| 달 변화 | 30일의 변화와 여섯 시점 기록 | 다음 예상 활동 진행 |
| 달 예상 | 예상 저장 후 나란히/겹쳐 비교 | 예상 모양과 최초 예상 저장, 성찰 작성 |
| 행성 | 현재 행성의 실제 3D 회전 | 관찰 특징 선택 |
| 천체 자료 | 천체 자료 관찰과 가림판 실험 | 다음 판별 활동 진행 |
| 별 관찰 | 현재 별 무리부터 두 구역 순차 관찰 | 다음 패턴 활동 진행 |
| 별 패턴 | 내 패턴 저장 후 기존 선과 기준선 비교 | 연결선 만들기, 최초 패턴 저장, 차이 작성 |

행성 순서·무리 분류와 별/행성 정답 판별에는 자동재생을 넣지 않았다. 자동재생은 정답·성찰 문장·학습자의 별 연결선·최종 완료 기록을 대신 작성하지 않는다. 관찰 과정에서 실제 표시한 사진·날짜·천체·별의 관찰 데이터는 기존 저장 경로에 기록한다.

## 구현

- `src/learning.js`: 공통 화면, 다음 조작 표시, 기존 활동을 사용하는 자동 관찰 단계와 입력/타이머 정리.
- `src/observation-player.js`: 재생·속도·정지·재마운트 타이머 수명 관리.
- `src/stage-viewport.js`, `src/responsive.css`: 한 화면 배치와 뷰포트 맞춤.
- `src/moon-stages.*`, `src/space-stages.*`: 화면별 중복 문구와 조작 압축, 관찰 영역 확대.
- `src/application.js`: 학습 화면 안의 공통 이동 버튼, 수동 활동 전환 시 재생 초기화.
- 기존 저장 스키마·정답 판정·완료/해금 조건과 사용자 수정 내용은 보존했다. 의존성이나 잠금 파일은 변경하지 않았다.

## 검증 결과

- `npm test`: 85개 통과. 재생 속도·일시정지·재마운트·숨김·모달·답안 비변경과 뷰포트 계산을 포함한다.
- `npm run build`: 통과.
- `scripts/verify-stage-fit.mjs`: 10개 화면 크기 × 41개 상태, 410개 고유 조합에서 필요한 스크롤·잘린 글자·가려진 조작·중복 문구·페이지 오류 0건.
- 크기: 1920×1080, 1366×768, 1280×800, 1024×600, 960×540, 873×412, 740×360, 360×740, 768×1024, 800×270.
- 상태: 빈 입력/작성된 기록, 각 탭, 겹쳐 보기, 가림판, 행성 2배 확대/3D. 달 그림 수정 후 관련 100개 조합을 전 해상도에서 재검사했다.
- `scripts/verify-observation-playback.mjs`: 실제 브라우저 재생·속도·일시정지·자동 관찰 데이터·정답 비선택·기록 보존·이탈 후 타이머 정리 11개 검증 통과.
- `scripts/verify-playthrough.mjs`: 수동으로 5개 미션 완료, 키보드/터치 드래그, 정답 수정, 코어 복구, 인증서와 새로고침 기록 보존까지 19개 검증 통과.
- JS 문법 검사와 `git diff --check` 통과. 대표 화면을 직접 열어 그림과 조작 배치를 확인했다.

결과는 `.tmp/stage-fit/verified-report.json`, 재생 검증은 `.tmp/stage-fit/playback-final/report.json`, 수동 학습 흐름은 `.cache/classroom-qa/playthrough.json`이다. 캡처와 원본 결과는 `.tmp/stage-fit/{final,lunar-recheck}/`에 보존했다. 모든 작업 파일·빌드·브라우저 프로필·캐시·임시파일은 확인된 외장 T7 Shield 경로를 사용했다.

물리 태블릿·모바일 키보드·Safari는 미실측이다. 긴 자료를 여는 모달과 긴 자유 서술의 입력란 내부 스크롤은 한 화면 실험/조작 배치와 별개다.
