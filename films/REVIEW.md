# 개념영상 5편 · HyperFrames 검토 노트 (2026-11-09)

## 구조

| 파일 | 역할 |
|---|---|
| `kit/kit.css`, `kit/kit.mjs` | 공용 부품: 관측 노트 바탕, 질문 장면, 이름표(점→선→이름표), 결론+캐릭터 반응, 효과음 배치, 장면 경계 `CUES=[0,3.6,8,12.2]`, 길이 16초 |
| `films.data.mjs` | 편별 질문·자막·결론·반응과 2·3장면 그림. 달 위상은 `src/drawing.js` `phase()/moonSVG()`, 별 위치는 `projectedStars`(HYG 좌표), 행성 이름·순서는 `src/data.js` |
| `build.mjs` | `stage-N/`(HyperFrames 프로젝트) 생성. 루미·별여우 포즈 시트에서 포즈를 잘라 쓰고, 쓰지 않는 그림·효과음은 지움 |
| `render.mjs` | 1920×1080 30fps 렌더 → 앱 경로 `public/assets/concepts/stage-N.{mp4,webm,webp}` 게시(1280×720, H.264+AAC faststart / VP9+Opus, 마지막 장면 포스터) |

실행: `RENDER_DIR=<외장 SSD 폴더> npm run concepts:render` (= `node films/build.mjs && node films/render.mjs`). 렌더 원본·`.hyperframes/`는 저장소에 넣지 않는다.

## 과학 확인

- 달 모양: 앱 `phase()` 그대로. 3·7일째 오른쪽, 22·27일째 왼쪽이 밝음(북반구 관찰), 15일째 보름달. 테스트로 고정.
- 별: HYG 좌표 투영(앱 별 지도와 같은 함수)을 북극성 중심으로 90° **회전만** 했다(하늘이 북극성 둘레를 도는 방향, 거울 뒤집기 없음). 북극성은 북두칠성과 카시오페이아자리 사이.
- 행성 크기·거리는 실제 비율이 아님을 화면과 자막에 표기. 교육과정 밖 개념(입자 모형·위상 원인 설명) 없음.

## 측정한 것 / 본 것

- `hyperframes check --json`: 5편 모두 오류 0. 남긴 경고: 루트 한 파일 구성이라 `nested_structure_needs_subcomposition`(편집 편의 경고), 같은 달 그림 여러 번 사용 `duplicate_media_discovery_risk`, 창 안 SVG `container_overflow`(창이 잘라 주는 의도된 겹침).
- `hyperframes snapshot`으로 편마다 6프레임 직접 확인, 게시된 mp4를 다시 디코드해 편마다 4프레임 확인.
- 소리: `hyperframes audio`로 측정(들어 보지는 못함). 1편 −18.2 LUFS, true peak −2.9 dB, 클리핑 0. 효과음 시점이 그림 시점보다 1프레임 뒤.
- 용량(1280×720): mp4 0.40~0.74MB, webm 0.34~0.56MB, 길이 16.00초.
