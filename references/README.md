## 적용 시 확인할 부분

- 01–10의 부엉이는 v2의 캐릭터 규칙과 충돌하므로 사용하지 않아. 달토끼 기록원·별여우 연구관을 유지해.
- 28번은 나선은하 이미지를 `스피카`로 표시해. 과학 이미지와 문구를 그대로 재사용하면 안 돼.
- 샘플에 구워진 한글·버튼·수치·정답 연결은 구현용 데이터가 아니야. 실제 UI와 과학 데이터로 다시 구성해야 해.
- 31–40의 달·행성·별자리는 배경에 합쳐져 있어. 학습 오브젝트와 겹치거나 정답을 미리 보여줄 수 있으므로, 장면별로 장식 배경과 관측 대상을 분리해야 해.
- 42–43은 여러 포즈를 모은 시트야. 바로 재생 가능한 보행 스프라이트나 개별 포즈 파일로 준비된 상태는 아니야.
- 2.5D 픽셀 맵, 타일·충돌 영역, 플레이어 보행 스프라이트, 검증된 행성 텍스처·별 좌표 데이터는 현재 자료에서 찾지 못했어.
- 제공 배경과 캐릭터는 부드러운 2D 일러스트 계열이야. 픽셀 스타일은 선택 맵에만 적용하고, 장소 진입 후 기존 시안의 2D 표현으로 전환해.

## 문서 충돌 정리

초기 PRD는 메인과 엔딩을 포함해 10개 화면을 세지만, v2는 학습 화면만 10개로 세고 메인·맵·엔딩을 따로 다뤄. 이번 논의안은 v2의 5장 × 2화면 구조를 사용해. 메인·선택 맵·결과까지 포함하면 전체 화면 수는 10개보다 많아.

초기 문서의 메인·별자리·엔딩 3D 정책보다 이번 사용자의 선택, 즉 **선택 맵만 2.5D, 학습은 2D, 행성 조사 대상만 3D**가 우선해.
