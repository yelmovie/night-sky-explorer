- **Project:** 아이스크림미디어 Science World
- **Title:** 별빛 관측 연구소
- **English working title:** Starlight Observation Lab
- **Repository:** `starlight-observation-lab`
- **GitHub Description:** `An interactive science learning game for 4th-grade students to observe the Moon, explore lunar changes, investigate the Solar System, compare stars and planets, and examine constellations around Polaris.`
- **대상:** 초등학교 4학년
- **교과/학기:** 과학 4학년 2학기 「밤하늘 관찰」

- **플랫폼:** Tablet-first Web / PWA-ready, 16:9 가로형 우선
- **권장 플레이 시간:** 30~40분

- **문서 버전:** 1.0
- **작성일:** 2026-08-25

## 1. 제품 한 줄 정의

학생이 밤하늘 개념을 읽고 정답을 누르는 대신 **관측 → 확대·조정 → 증거 수집 → 시간 비교 → 예측 → 검증 → 3D 조사·구성 → 근거 판별 → 별자리 패턴 관찰 → 개인 기록 통합**을 수행하며 달·태양계·별·북극성 주변 별자리를 탐구하는 초등 4학년 과학 게임.

## 2. 제품 목표

이 제품은 교과서·PPT·활동지를 화면에 옮긴 디지털 문제집이 아니다. 핵심 질문은 다음과 같다.

> **“왜 굳이 태블릿을 써야 하는가?”**

제품은 다음 기능으로 답한다.

1. 망원경 시야를 손가락으로 이동하고, 핀치로 확대하며, 원형 초점링을 조절한다.
2. 여러 날의 달 변화를 시간 슬라이더로 압축 관찰하고, 자신이 만든 예측과 실제 관측 상태를 중첩 비교한다.
3. 3D 행성을 직접 회전·확대·스캔하여 관찰 가능한 특징을 모은다.
4. 앞 화면에서 모은 행성 관측자료를 태양계 모형 제작의 실제 근거로 다시 사용한다.
5. 별과 행성을 분류할 때 이름만 맞히지 않고 **판정 + 근거 연결**을 수행한다.
6. 별자리 선이 없는 상태에서 북극성 주변 별 배열을 먼저 관찰하고, 자신이 만든 패턴과 기준 레이어를 겹쳐 비교한다.
7. 학생별 달 관측사진·예측·행성 증거·판별 근거·별자리 패턴이 최종 관측 기록으로 남는다.
8. 3D는 장식이 아니라 회전·공간관찰·배치가 학습에 필요한 화면에서만 사용한다.

### 핵심 학습 루프

**관찰 → 증거 수집 → 비교 → 규칙 발견 → 예상/구성 → 검증 → 기록 → 수정**

## 3. 직접 적용 성취기준

### [4과13-01]
**달의 모양과 표면, 달의 위상변화를 관찰하여 밤하늘 관찰에 흥미를 가질 수 있다.**

반영:
- Stage 1: 달 포착, 초점 맞추기, 달 표면 영역 관찰·비교
- Stage 2: 여러 날의 달 모양 변화 관찰, 관측 기록, 이후 모습 예상·검증

### [4과13-02]
**태양계 구성원을 알고, 태양과 행성을 조사할 수 있다.**

반영:
- Stage 3 전반: 이름이 가려진 3D 행성을 회전·확대·스캔하여 관찰 가능한 특징 수집
- Stage 3 후반: 태양과 8개 행성으로 학습용 태양계 모형 구성

### [4과13-03]
**별의 정의를 알고, 북극성 주변의 별자리를 관찰할 수 있다.**

반영:
- Stage 4: 별과 행성의 공통점·차이점 비교, 별의 정의를 근거로 판별
- Stage 5: 북극성 주변 영역에서 별 배열을 직접 관찰하고 별자리 패턴 기록·비교

## 4. 4학년 범위 가드레일

### 반드시 다룬다
- 달의 전체 모양과 표면의 관찰 가능한 특징
- 여러 날 동안 달 모양이 달라지는 현상
- 관찰 기록을 바탕으로 이후 모습을 예상하는 사고
- 태양계 구성원
- 태양과 행성의 관찰 가능한 특징
- 태양계 행성 모형 구성
- 별과 행성의 공통점·차이점
- **별 = 스스로 빛을 내는 천체**라는 정의
- 북극성 주변 별자리 관찰

### 본편 핵심 평가에서 제외한다
- 달 위상변화의 원인을 태양-지구-달 위치로 설명하기
- 달의 자전·공전 원리
- 지구에서 달의 뒷면이 보이지 않는 이유
- 태양·지구 자전 방향
- 음력 날짜 암기 중심 문제
- 행성의 정확한 질량·지름·거리·공전주기 계산
- 계절별 별자리 변화 원인
- 북두칠성·카시오페이아자리 등을 이용해 **북극성의 위치를 찾아내는 것**을 필수 미션으로 만들기
- 제임스 웹·적외선 원리를 본편 필수 평가로 넣기

### 과학 표현 정확성
- 실제 사진/관측자료와 학습용 3D 모형을 구분한다.
- 태양계 제작 화면에는 **“학습용 모형 — 실제 크기와 거리 비율이 아님”**을 표시한다.
- 별자리 연결선은 사람이 별의 배열을 이해하기 위해 덧붙인 표현임을 유지한다.
- 별 위치·별자리 기준선은 검수된 데이터로 관리하고 아트팀이 임의로 만들지 않는다.

## 5. 첨부자료 벤치마킹 원칙

첨부 자료는 **기능과 학습효과를 높이기 위한 참고자료**로만 사용한다. 캐릭터·레이아웃·문항·이미지·앱 UI·게임 규칙은 그대로 복제하지 않는다.

### A. 스텔라리움 별·행성 비교 수업
참고:
- 날짜·시간 조절
- 밤하늘 이동·확대/축소
- 별과 행성을 같은 관측 화면에서 비교
- 관찰 뒤 공통점·차이점 정리

변환:
- 외부 사이트 검색/접속 절차를 제거하고 게임 내부 관측기로 통합
- `관측 → 증거 → 판정 → 근거` 구조로 변환

복제하지 않음:
- 스텔라리움 UI, 쿠키·위치권한 안내, QR, 영어 검색 절차, 슬라이드 화면

### B. Sky Tonight 별자리 수업
참고:
- 확대·축소·드래그
- 날짜·시간 변경
- 실제 하늘과 스마트 기기 화면을 비교하는 관측 사고
- 북극성 주변 별자리 관찰

변환:
- 앱 설치 없이 게임 내부 관측 돔으로 구현
- 별자리 선을 처음부터 보여주지 않고 `학생 패턴 → 기준 레이어 비교`로 확장
- 기기 방향 센서는 선택 기능으로만 사용

### C. 여러 날의 달 / 달 모양 변화 자료
참고:
- 여러 날짜의 달 관찰
- 초승→상현→보름→하현→그믐 흐름 관찰
- 변화 규칙을 보고 다음 모습을 생각하는 구조

변환:
- 스티커·달력 붙이기를 `시간 슬라이더 → 관측사진 저장 → 예측 제작 → 중첩 비교`로 변환

복제하지 않음:
- 원본 달력·스티커 레이아웃, 6학년용 자전·공전, 음력 암기 활동

### D. 단원정리 퀴즈 자료
참고:
- 짧은 개념 회상의 역할만 참고

변환:
- 본편이 아니라 Screen 10의 개인별 오류복구 미션 풀에 한정

복제하지 않음:
- 캐릭터 IP, 배틀 점수 규칙, 원본 문항, 4학년 범위 밖 내용

### E. 제임스 웹/달 더 알아보기 자료
참고:
- 호기심을 일으키는 질문 방식
- 학습 후 선택 확장 콘텐츠 구조

변환:
- 본편 완료 뒤 선택형 “비밀 연구노트” 후보
- 성취 판정에는 반영하지 않음

## 6. 세계관

산 정상의 **별빛 관측 연구소**가 밤하늘 데이터를 제대로 기록하지 못하고 있다. 연구소에는 다섯 개의 관측 시스템이 있다.

1. 달 표면 관측기
2. 달빛 시간 기록기
3. 태양계 연구 장치
4. 별빛 판별 장치
5. 북극성 주변 관측 돔

학생은 신입 관측 연구원으로서 각 장치를 복구한다. 각 Stage에서 연구 데이터 하나를 얻고, 다섯 데이터가 모이면 중앙 천문 돔이 열리며 **「나의 밤하늘 관측 기록」**이 완성된다.

연구 데이터:
- `moon_surface_data`
- `moon_timeline_data`
- `solar_system_data`
- `star_planet_data`
- `constellation_data`

## 8. Stage 1 — 달 표면 관측

### Screen 02 — 망원경으로 달을 포착하라

학생 행동:
1. 달이 중앙에 없는 밤하늘에서 망원경 시야를 드래그한다.
2. 달을 포착한다.
3. 핀치로 배율을 조절한다.
4. 원형 초점링을 돌려 선명도를 맞춘다.
5. 일정 시간 관측 가능 상태를 유지한 뒤 촬영한다.

난이도 원칙:
- “달을 누르세요” 금지
- 위치·배율·초점을 함께 조절하되 픽셀 단위 정밀 조작은 요구하지 않음
- 핀치가 어려운 학생을 위해 +/- 버튼 fallback 제공

### Screen 03 — 달 표면의 증거를 기록하라

학생 행동:
1. 달 표면에서 서로 다른 지점 3곳 이상을 직접 고른다.
2. 돋보기/스캔으로 확대한다.
3. 관측핀과 사진을 저장한다.
4. 두 사진을 나란히 놓고 공통점·차이점을 기록한다.

핵심:
- 특정 정답 지점을 클릭하는 것이 아니라 **학생이 관찰 지점을 선택**한다.
- 밝고 어두운 부분, 움푹 팬 형태 등 눈으로 확인 가능한 특징만 사용한다.

Stage 1 완료 데이터: `moon_surface_data`

## 9. Stage 2 — 달빛 시간 기록

### Screen 04 — 여러 날의 달을 기록하라

학생 행동:
1. 검수된 학습용 시간 시퀀스의 타임라인을 이동한다.
2. 서로 충분히 떨어진 여러 시점의 달을 촬영한다.
3. 자신의 관측 달력에 저장한다.
4. 처음/중간/나중 모습을 비교한다.

주의:
- 실시간 천문달력처럼 가장하지 않는다.
- 기본은 **학습용 시간 압축 관측**으로 표시한다.
- 날짜 암기보다 변화 자체의 관찰이 목적이다.

### Screen 05 — 다음 달 모습을 예측하라

학생 행동:
1. 일부 시점이 비어 있는 관측 기록을 본다.
2. 앞선 변화에서 규칙을 찾는다.
3. 밝은 영역 조절기로 예상 달 모습을 직접 만든다.
4. 예측을 잠근다.
5. 시간을 진행한다.
6. 예상과 실제를 반투명 중첩한다.
7. 필요하면 한 번 수정한다.

4지선다 달 이미지 선택 대신 **자기 예상 생성 → 실제 검증**을 사용한다.

Stage 2 완료 데이터: `moon_timeline_data`

---

## 10. Stage 3 — 태양계 연구

### Screen 06 — 미확인 행성을 분석하라

학생 행동:
1. 이름이 가려진 3D 행성을 회전한다.
2. 핀치로 확대한다.
3. 서로 다른 영역/구조를 스캔한다.
4. 색, 줄무늬, 고리 등 관찰 가능한 증거를 모은다.
5. 최소 증거 수를 확보한 뒤 후보를 판단한다.

오답 처리:
- 빨간 X로 끝내지 않는다.
- “어떤 증거를 더 보면 좋을지”를 알려주고 3D 관찰로 돌려보낸다.

### Screen 07 — 태양계 홀로그램을 완성하라

학생 행동:
1. 태양과 8개 행성 구성원을 확인한다.
2. 학습용 궤도 슬롯에 행성을 배치한다.
3. 최소 두 번 이상 Screen 06 관측자료를 다시 열어 근거를 확인한다.
4. 틀린 배치를 수정한다.
5. 완성된 모형을 회전 관찰한다.

필수 표시:
> **학습용 모형이며 실제 행성의 크기와 거리 비율과 같지 않습니다.**

Stage 3 완료 데이터: `solar_system_data`

## 11. Stage 4 — 별빛 판별

### Screen 08 — 별과 행성을 증거로 판별하라

학생 행동:
1. 가상의 밤하늘을 드래그·확대한다.
2. 여러 관측대상을 선택한다.
3. 관측자료를 확인한다.
4. `별 / 행성` 판정을 한다.
5. 반드시 판단 근거를 연결한다.

판정만 맞아도 완료되지 않는다.

핵심 근거:
- 별은 스스로 빛을 내는 천체이다.
- 별과 행성 모두 밤하늘에서는 빛나는 작은 점처럼 보일 수 있다.

밝기나 화면상 크기 하나로 무조건 판별하게 하지 않는다.

Stage 4 완료 데이터: `star_planet_data`

## 12. Stage 5 — 북극성 주변 관측

### Screen 09 — 북극성 주변 별자리를 관찰하라

4학년 범위에 맞게 **“북극성을 찾아내기”가 아니라 “북극성 주변 별자리를 관찰하기”**로 설계한다.

학생 행동:
1. 시스템이 북극성 주변 관측 영역을 지정한다.
2. 연결선 없는 별 배열을 먼저 살펴본다.
3. 눈에 띄는 별을 선택해 자신이 본 패턴을 연결한다.
4. 기준 별자리 레이어를 켠다.
5. 학생 선과 기준 선을 반투명 중첩해 비교한다.
6. 관찰한 별자리를 연구노트에 기록한다.

선택 기능:
- DeviceOrientation 지원 시 태블릿 방향으로 하늘 보기
- 권한 거부/미지원 시 manual drag로 동일하게 완주

Stage 5 완료 데이터: `constellation_data`

## 13. Screen 10 — Final 연구소 복구

Final은 고정 20문항 단원평가가 아니다.

### 1단계: 개인별 오류복구
이전 기록의 오개념/재시도 태그를 확인한다.

예:
- `moon_surface_observation_weak`
- `moon_sequence_confusion`
- `planet_evidence_weak`
- `star_definition_confusion`
- `constellation_pattern_weak`

필요할 경우 최대 3개의 짧은 **수행형** 복구 미션을 제공한다.

예:
- 달 표면 두 지점을 다시 비교
- 비어 있는 달 시점 다시 예상
- 행성 관측 증거 한 개 보강
- 별/행성 판정 근거 다시 연결
- 별자리 패턴 일부 다시 관찰

오류가 거의 없으면 불필요한 문제를 억지로 주지 않는다.

### 2단계: 연구소 복구
다섯 연구 데이터를 중앙 장치에 연결한다. Screen 01의 동일 연구소가 복구 상태로 바뀌고 천문 돔이 열린다.

### 3단계: 개인 결과
**「나의 밤하늘 관측 기록」**
- 달 표면 관측사진
- 달 변화 기록 및 예측
- 행성 조사 증거
- 태양계 모형 완료 기록
- 별/행성 판별 근거
- 북극성 주변 별자리 패턴
- 수정/재도전 기록

학생 이름은 결과 PNG/인쇄 직전에 선택 입력하며 지속 저장하지 않는다.

## 18. 접근성·수업 사용성

- 핵심 터치 영역 최소 44×44 CSS px
- 색상만으로 상태 구분하지 않음
- 모든 한글은 DOM/CSS/SVG로 구현
- 작은 별 선택에는 확대 hit area 제공
- `prefers-reduced-motion` 지원
- 오디오 없이 전체 완주 가능
- DeviceOrientation 없이 전체 완주 가능
- 핀치 조작에는 +/- 버튼 fallback 제공
- 3D hotspot에는 동등한 DOM 접근 버튼 제공
- 교사용 전체 해금은 Science World 공통 설정 정책 재사용
